Print the JSON schema for CLI output

Usage: pybun schema print [OPTIONS]

Options:
      --format <FORMAT>
          Output format for machine readability [default: text] [possible values: text, json]
      --schema-version <SCHEMA_VERSION>
          Contract version to print; v1 remains frozen for native compatibility [default: 1] [possible values: 1, 2]
      --progress <PROGRESS>
          Progress UI mode (auto hides on non-TTY) [env: PYBUN_PROGRESS=] [default: auto] [possible values: auto, always, never]
      --no-progress
          Disable progress UI
  -h, --help
          Print help
